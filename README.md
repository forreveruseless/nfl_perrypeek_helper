## ✨ Что умеет сайт

**NFLPerry NBA Assistant** — локальный/статический помощник для NBA Pick 'Em / SIM на NFLPerry.

| Возможность | Что делает |
|---|---|
| 📚 Точная база | Использует snapshot ответа NFLPerry `nba-fantasy?mode=bestSeason` |
| 🔎 Поиск | Фильтрация по команде, позиции и имени |
| ⭐ FPTS | Показывает рейтинг, сезон, PTS, REB и AST |
| 🎯 Помощник по пику | Ранжирует игроков текущей выпавшей команды |
| 🧠 Потенциальный максимум | Считает лучший возможный суммарный FPTS для **всех уже выпавших команд** |
| 🧩 Учёт позиций | PG / SG / SF / PF / C / 6TH, включая универсальные G и F |
| 🔁 Повтор команды | Если одна команда выпала несколько раз, один игрок не используется дважды |
| 💾 Автосохранение | История дроу, текущий состав и ручные поправки хранятся в браузере |
| 🔄 Live Exporter | Userscript позволяет позже выгрузить свежую базу NFLPerry |

## 🧠 Как работает «Потенциальный максимум»

Допустим:

1. выпал **CHI**;
2. ты добавляешь CHI в историю;
3. сайт показывает максимально возможный FPTS для одного игрока Chicago;
4. следующим выпал **WAS**;
5. добавляешь WAS;
6. сайт пересчитывает **лучшую совместимую пару CHI + WAS** с учётом разных слотов.

Это не просто сумма двух самых больших чисел.

Алгоритм ищет математически лучшую комбинацию, соблюдая ограничения:

- один игрок на каждый выпавший дроу;
- PG / SG / SF / PF / C можно занять только один раз;
- 6TH универсален;
- игрок должен подходить позиции;
- при повторном выпадении одной команды нельзя использовать одного и того же игрока дважды;
- максимум пересчитывается после каждого нового дроу.

При шести выпавших командах сайт проверяет все допустимые назначения по шести слотам и выбирает комбинацию с максимальным суммарным FPTS.

## 🚀 Запуск через GitHub Pages

Репозиторий должен выглядеть так:

```text
nfl_perrypeek_helper/
├── index.html
├── README.md
├── nflperry_api_snapshot.json
└── nflperry_exporter.user.js
```

Дальше:

1. Открой **Settings** репозитория.
2. Перейди в **Pages**.
3. В `Build and deployment` выбери **Deploy from a branch**.
4. Branch: `main`.
5. Folder: `/ (root)`.
6. Нажми **Save**.

После публикации сайт будет доступен по адресу:

```text
https://forreveruseless.github.io/nfl_perrypeek_helper/
```

## 📦 Обновление базы NFLPerry

В комплекте есть:

```text
nflperry_exporter.user.js
```

Это userscript для Tampermonkey. На `nflperry.com` он добавляет кнопку **Export NBA DB**.

После экспорта:

1. скачай JSON;
2. открой вкладку **База NFLPerry** в Assistant;
3. выбери импорт JSON;
4. сайт начнёт использовать свежую базу.

Текущий источник данных:

```text
https://api.nflperry.com/players/nba-fantasy?mode=bestSeason
```

## 💾 Сохранение данных

Сайт не требует собственного сервера или базы данных.

В браузере сохраняются:

- текущий состав;
- последовательность выпавших команд;
- ручные исправления FPTS;
- пользовательские настройки.

Для резервной копии есть кнопка **«Скачать мои настройки»**.

> `localStorage` привязан к адресу сайта.  
> Данные, введённые в локальный `index.html`, и данные на `github.io` хранятся отдельно.
